# Sources and licensing status

This repository is a research release assembled from the CoFiE working tree.

- The Qwen3-VL model and processor files retain their upstream copyright and license notices.
- Evaluation scripts and method-specific modifications include inherited CoFiE changes and references to upstream projects.
- The repository does not assign a blanket MIT or Apache-2.0 license to every inherited modification.
- The source project describes code, data, and checkpoints as research-use-only. Review redistribution permissions before publishing derivatives.
- Model checkpoints and benchmark datasets are not included. Their own licenses and terms apply independently.

Third-party sources include Qwen3-VL, Transformers, TimeChat-Online, VideoLLM-online, StreamingBench, and benchmark-specific tooling. Preserve their notices and attribution requirements. The Apache license text used by the inherited Transformers components is included in THIRD_PARTY_LICENSES.txt.
